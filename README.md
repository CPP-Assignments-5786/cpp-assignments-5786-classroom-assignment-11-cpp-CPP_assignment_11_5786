# מטלה אחת-עשרה - מצביעים חכמים, Move ו-Rvalue Reference, מחסנית

## יושרה אקדמית

במהלך העבודה על המטלות, מותר להתייעץ עם סטודנטים אחרים ולחפש מידע באינטרנט. עם זאת, חל איסור להעתיק קטעי קוד שלמים ממקורות חיצוניים, כולל סטודנטים אחרים, אתרי אינטרנט ומודלי בינה מלאכותית (כגון ChatGPT).

יש לדווח על כל עזרה שקיבלתם, בין אם מדובר בהתייעצות עם סטודנטים אחרים או במידע שנמצא באינטרנט, בהתאם ל[תקנון היושר של המחלקה](https://www.ariel.ac.il/wp/cs/wp-content/uploads/sites/88/2020/08/Guidelines-for-Academic-Integrity.pdf).
**במקרה של שימוש בכלי בינה מלאכותית (AI), יש לצרף את הפרומפטים שהוזנו ואת התשובות שהתקבלו**.

## הקדמה
מטלה זו היא חלק מהקורס "C++ תכנות מתקדם" והיא המטלה האחרונה בסדרה. מטרתה להדגים את הנושאים המתקדמים ביותר: **מצביעים חכמים (Smart Pointers)**, **סמנטיקת העברה (Move Semantics)**, **הפניות Rvalue**, ו-**weak_ptr**. המטלה מתמקדת ביישום מערכת ישויות למנוע משחק תוך שימוש ב-`unique_ptr`, `shared_ptr`, `weak_ptr`, ובנאי/אופרטור העברה.

## מבנה המטלה
במטלה זו תתבקשו לממש מספר קבצי `.cpp` ו-`.hpp` על בסיס הדרישות שהוגדרו. המטלה מדגימה:
- **std::unique_ptr** — בעלות בלעדית על ישויות
- **std::shared_ptr** — בעלות משותפת על משאבים
- **std::weak_ptr** — הפניה חלשה שלא מונעת מחיקה
- **Move Constructor** — בנאי העברה להעברת בעלות
- **Move Assignment Operator** — אופרטור השמה בהעברה
- **std::move** — המרה ל-rvalue reference
- **Rvalue References (&&)** — הפניות לערכי ימין
- **מחסנית עם unique_ptr** — מימוש linked-list stack עם מצביעים חכמים

- ליצור ולממש את קבצי ה-`.cpp` ו-`.hpp` הנדרשים (פירוט ב-**קבצים במטלה**)
- לוודא שהקוד מתקמפל ופועל ללא שגיאות
- **אין להשתמש ב-new/delete ישירות** — יש להשתמש ב-`make_unique` ו-`make_shared` בלבד
- לעבור בהצלחה את הטסטים הכתובים בקובץ test.cpp

## תכונות C++ שיש להדגים
1. **std::unique_ptr** — בעלות בלעדית, `std::make_unique`, העברה עם `std::move`
2. **std::shared_ptr** — בעלות משותפת, `std::make_shared`, `use_count()`
3. **std::weak_ptr** — הפניה חלשה, `lock()`, `expired()`
4. **Move Constructor** — `Entity(Entity&& other) noexcept`
5. **Move Assignment** — `Entity& operator=(Entity&& other) noexcept`
6. **std::move** — המרה מ-lvalue ל-rvalue
7. **מחסנית עם unique_ptr** — רשימה מקושרת ללא דליפות זיכרון
8. **בדיקות יחידה (Unit Testing)** — שימוש בספריית doctest

## טיפים להשלמת המטלה
- קראו היטב את הוראות המטלה והבינו את הדרישות
- **בידקו את קובץ `test.cpp` ו-`main.cpp`** — הם מגדירים את הפורמט המדויק של הפלט הצפוי ואת ההתנהגות הנדרשת
- **`unique_ptr`** — לא ניתן להעתיק, רק להעביר (`std::move`)
- **`shared_ptr`** — ניתן להעתיק, כל עותק מגדיל את ספירת ההפניות
- **`weak_ptr`** — לא מגדיל את ספירת ההפניות, חייב להמיר ל-`shared_ptr` עם `lock()` לפני שימוש
- **Move constructor** — מעביר את המשאבים מאובייקט אחד לאחר, משאיר את המקור במצב ריק/תקין
- **Move assignment** — דומה ל-move constructor, אבל יש לטפל ב-self-assignment ובמצב הקודם של `this`
- **`noexcept`** — חשוב לציין על move constructor/assignment כדי שמכולות STL ישתמשו בהם
- **אל תשתמשו ב-`new`/`delete`** — השתמשו ב-`make_unique`/`make_shared`
- שימו לב לטיפול ב-**מקרי קצה**: אינדקסים שליליים, רשימות ריקות, self-assignment, ערכים לא חוקיים
- הקפידו על כתיבת קוד נקי, קריא ומתועד היטב
- זכרו ליצור קובץ **StudentTest.cpp** עם לפחות 20 מקרי בדיקה
